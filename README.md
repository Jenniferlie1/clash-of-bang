# Clash of BaNG

Situs web komunitas untuk game strategi fantasi "Clash of BaNG" — dibangun dengan HTML, CSS, dan JavaScript.

## Overview
Clash of BaNG adalah komunitas gaming bertema fantasi yang didirikan pada 2018 oleh para penggemar game strategi. Situs ini menampilkan profil komunitas, galeri seni fan, panduan troop, dan formulir pendaftaran anggota.

## Halaman
- **Home** (`home.html`) — Hero section, ringkasan komunitas, troop populer, dan update game terbaru
- **About** (`about.html`) — Sejarah komunitas (timeline 2018–sekarang), hub regional (Jakarta, Bandung, Sanur), dan profil pendiri
- **Gallery** (`gallery.html`) — Galeri visual hub regional, hero, dan artwork komunitas
- **Troops** (`troops.html`) — Daftar troop/unit dalam game
- **Register** (`register.html`) — Formulir pendaftaran anggota baru (nama, email, usia, troop favorit, dll)

## Tech Stack
`HTML5` `CSS3` `JavaScript`

Font: [Cinzel](https://fonts.google.com/specimen/Cinzel) & [Poppins](https://fonts.google.com/specimen/Poppins) via Google Fonts
