# Clash of BaNG

A community website for the fantasy strategy game "Clash of BaNG" — built with HTML, CSS, and JavaScript.

## Overview
Clash of BaNG is a fantasy-themed gaming community founded in 2018 by strategy game enthusiasts. The site showcases the community's profile, fan art gallery, troop guides, and a member registration form.

## Pages
- Home (home.html) — Hero section, community overview, popular troops, and latest game updates
- About (about.html) — Community history (timeline from 2018–present), regional hubs (Jakarta, Bandung, Sanur), and founder profiles
- Gallery (gallery.html) — Visual gallery of regional hubs, heroes, and community artwork
- Troops (troops.html) — List of troops/units in the game
- Register (register.html) — New member registration form (name, email, age, favorite troop, etc.)

## Tech Stack
`HTML5` `CSS3` `JavaScript`
